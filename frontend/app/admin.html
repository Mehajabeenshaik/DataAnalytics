Metric Approval

Review metric proposals the agent wants to add to the governed catalog. Approving lets the LLM planner use a metric; rejecting keeps it out.

Sign in (admin)

Sign in with a bootstrap admin. On first boot a random password is generated and printed to the server console. (Set BOOTSTRAP_ADMIN_PASSWORD in .env to control it.)
